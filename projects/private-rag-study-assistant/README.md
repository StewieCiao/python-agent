# 私有资料 RAG 学习助手

## 用户故事

学习者把自己的 Markdown、TXT、CSV 或 PDF 资料导入本机，提出问题后得到带来源的回答；资料没有足够相似内容时，助手必须明确回答“资料不足”，不能编造答案。

## 架构与数据流

`本地文件 → 解析与 metadata → 分块 → embedding → 相似度检索 → 引用生成 → 质量评测`

桌面端通过内置 Python 服务完成解析和检索，模型请求只经本地服务转发。每条结果保留来源文件和页码，评测记录保存课程哈希、资料哈希、召回率、MRR、引用覆盖率和耗时。

## 演示脚本

1. 导入两份主题不同的资料，确认来源 metadata 被保留。
2. 提问一个只在第一份资料出现的问题，展示命中文档和引用。
3. 提问资料外的问题，展示“资料不足”且没有模型调用。
4. 运行固定问答集评测，记录 recall@k、MRR 和引用覆盖率。

## 已知限制

首版使用本地小规模资料和配置的 embedding 模型，不声称替代生产级分布式向量数据库；模型未返回 token usage 时，成本指标显示为不可用。
