# Stewie LearnOS v1.0.0

状态：发行说明草稿，安装包尚未发布。下列文件名为计划名称，不代表资源已存在。

## 下载

- Windows x64：`stewie-learnos-1.0.0-windows-x64-setup.exe`
- Windows ARM64：`stewie-learnos-1.0.0-windows-arm64-setup.exe`
- macOS Intel：`stewie-learnos-1.0.0-macos-x64.dmg`
- macOS Apple Silicon：`stewie-learnos-1.0.0-macos-arm64.dmg`
- 单文件离线版：`stewie-learnos-1.0.0-offline.html`
- 校验：`SHA256SUMS.txt`

发行准备会检查四个平台各有且仅有一个安装器，统一复制为上述 ASCII 名称，并对实际输出文件计算 SHA-256。根包与桌面包版本必须一致，Git 标签必须等于 `v` 加包版本，否则停止发布。Squirrel 的辅助 nupkg 不作为首次安装下载文件；当前没有配置自动更新服务。

桌面安装包是未签名的内部发行包。下载后先核对 SHA-256，再按系统提示确认来源；不需要关闭系统整体安全防护。

## 版本边界

- 桌面版：内置 Python、Pyodide、课程快照和本地服务；可执行练习、保存本地进度、使用本地资料库和配置 OpenAI-compatible 模型。
- Pages：静态课程浏览，不执行学习者代码，不接收 API Key。
- 离线 HTML：单文件静态课程浏览，不联网、不执行代码，草稿和完成标记只保存在当前浏览器。
