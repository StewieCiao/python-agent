# Stewie LearnOS v1.0.0

发布入口：<https://github.com/StewieCiao/python-agent/releases/tag/v1.0.0>

## 下载

- Windows x64：文件名包含 `windows-2025`
- Windows ARM64：文件名包含 `windows-11-arm`
- macOS Intel：文件名包含 `macos-15-intel`
- macOS Apple Silicon：文件名包含 `macos-15`
- 单文件离线版：`stewie-learnos-1.0.0-offline.html`
- 校验：`SHA256SUMS.txt`

桌面安装包是未签名的内部发行包。下载后先核对 SHA-256，再按系统提示确认来源；不需要关闭系统整体安全防护。

## 版本边界

- 桌面版：内置 Python、Pyodide、课程快照和本地服务；可执行练习、保存本地进度、使用本地资料库和配置 OpenAI-compatible 模型。
- Pages：静态课程浏览，不执行学习者代码，不接收 API Key。
- 离线 HTML：单文件静态课程浏览，不联网、不执行代码，草稿和完成标记只保存在当前浏览器。
