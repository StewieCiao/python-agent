# Stewie LearnOS：学习计划与简历项目建议

## 推荐学习顺序

1. Python：数据结构、函数、异常、模块、测试和工程习惯。
2. LangChain：消息与 Prompt → Runnable → 文档加载/切分 → Embedding/向量检索 → RAG 生成与引用 → 评估观测。
3. LangGraph：StateGraph → 路由与循环 → checkpoint → thread 短期状态 → Store 长期记忆 → interrupt/恢复 → 多 Agent。
4. 每个阶段先完成小练习，再把同一能力合并到项目；错题只在本地记录，个性题由已验证 family 生成。

## 可写入简历的个人项目

### 1. 私有资料 RAG 学习助手（推荐主项目）

本地导入 Markdown/PDF，经过切分、向量检索、引用生成和无资料拒答，回答必须附来源片段。展示召回命中、引用覆盖率、延迟和失败样例。技术重点是 LangChain retrieval、结构化输出和可观测性。

### 2. 可恢复的研究工作流 Agent

用 LangGraph 编排“规划 → 检索 → 摘要 → 事实核对 → 人工确认”，为每个用户使用独立 `thread_id`，用 checkpoint 支持中断后恢复，并把长期偏好放入 Store。展示状态转移图、恢复演示和错误边界。

### 3. 面向学习者的自适应编程教练

将真实执行结果、失败测试和掌握度事件转换为错题模式，再从可信练习 family 生成同能力新题；模型只负责解释，不参与通过/失败判定。展示个性题前后通过率、提示使用次数和复习队列变化。

## 项目验收标准

- README 写清问题、架构、数据流、运行方式和已知限制。
- 提供固定小数据集、可重复测试和失败示例，不用截图代替证据。
- API Key 只保存在用户本机安全存储；离线版不包含模型配置、聊天或网络调用。
- 记录真实上游错误、检索结果和引用，不用空回答或静态样例伪装成功。
