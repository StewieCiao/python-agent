# Stewie LearnOS 零部署使用指南

## 直接打开（无需安装、不执行代码）

下载仓库根目录的 `Stewie-个人学习站-离线版.html`，在任意现代浏览器中双击打开即可。文件内嵌课程、练习、提示、答案和项目说明，不加载外部脚本、不联网、不执行学习者代码，也不会请求或保存 API Key。

文件本身不发起网络请求；主动点击视频和官方资料链接仍需联网。编辑器的“静态检查”不等于运行或测试通过。“标记已完成”是自我记录。草稿保存在当前浏览器，不会写回 HTML；更换浏览器、清理存储、使用隐私窗口或改变文件路径可能导致记录不可见。当前没有离线记录导出/导入按钮，重要代码请另存文件。

## GitHub Pages（无需下载）

访问公开站点：<https://stewieciao.github.io/python-agent/>。

Pages 版本适合浏览课程和离线学习内容。它与离线 HTML 使用同一份作者目录生成，因此不会出现课程内容分叉；浏览器端不提供模型密钥输入和本地服务能力。

## 桌面下载状态

v1.0.0 安装包及校验清单尚未正式发布；当前不要把旧标签当成可下载安装包。发布后 Windows 按 x64 或 ARM64 选择文件，macOS 按 Intel 或 Apple Silicon 选择文件。现阶段的静态课程入口与离线文件见 [README](../README.md)。

## 桌面完整版（需要安装一次）

需要真实执行 Python、运行本地 RAG 或调用 OpenAI-compatible 模型时，安装 GitHub Release 中对应平台的桌面包。桌面包自带 Python、LangChain/LangGraph 和本地服务，用户不需要另装 Node.js 或 Python。

API Key 只在桌面端提交，由 Electron safeStorage 加密：macOS 使用钥匙串机制，Windows 使用 DPAPI。加密密文保存在本地 SQLite，明文不写入 SQLite、学习导出文件、日志或聊天历史，也不回显页面；安全存储不可用时明确失败，不会退回明文保存。换电脑或系统账号后需要重新配置 Key。

### macOS 安装

1. 苹果菜单 → 关于本机：Apple M 系列选择 ARM64，Intel 选择 x64。
2. 从可信来源下载对应架构的包，核对发布方校验清单。两个架构的 DMG 可能同名，不能只看文件名。
3. 打开 DMG，将 `Stewie LearnOS.app` 复制到“应用程序”或固定目录，然后推出镜像。
4. 从固定目录打开 app，不要长期从 DMG 运行。若有旧同名应用，先退出并确认新入口。
5. 未签名包可能被 Gatekeeper 拦截。先确认来源，按系统针对该应用的提示或管理员要求处理；不关闭整机安全防护。明确提示恶意软件或损坏时停止并反馈。

### Windows 安装

1. 设置 → 系统 → 关于 → 系统类型：区分基于 x64 与基于 ARM 的处理器。两者都可能显示“64 位”。没有 32 位安装包。
2. 下载对应架构的包；ZIP 先解压，再运行 `Stewie-LearnOS-Setup.exe`。不要反复双击。
3. 安装后从开始菜单或快捷方式打开应用，不要每次重新运行 Setup。无需安装 Python、Node.js、GitHub CLI，也无需启动服务器。
4. SmartScreen 或企业策略拦截时先确认来源及校验值，必要时交管理员处理；不要关闭杀毒软件或系统防护。

当前实体 Windows 用户曾报告 `Python 服务请求 health 超时（10000ms）`，根因仍待故障电脑日志；CI 通过不能证明该电脑已修复。该错误发生在本地服务启动，不是 API 模型请求，不应通过修改模型超时或清空学习数据来处理。请提供系统版本、架构、安装包来源、复现步骤与完整错误，不要发送 Key 或私人数据库。

### 首次学习

1. 核对课程数：Python 64、LangChain / RAG 48、LangGraph 42。看到 25 / 7 / 7 通常是旧应用副本。
2. Python 就绪后进入课程，先读知识讲解、输入输出要求与提示，再在编辑器编写代码。
3. 点击“运行代码”（或编辑区内 Ctrl/⌘ + Enter），区分程序输出、Python 异常与练习断言失败。无限循环的 4 秒超时不是测试未通过，等待执行环境恢复后再运行。
4. 修改代码后重新运行，旧结果不代表当前代码。查看错题本时可载入当时的代码复习。
5. LangChain / LangGraph 课程的依赖代码按页面说明在相应项目环境执行；普通编辑区不承诺运行任意第三方库。

### 配置模型与课程导师

1. 打开“模型设置”，填写配置 ID、名称、Base URL、模型名称、API Key、temperature、max tokens、超时（毫秒）。协议为 OpenAI-compatible，不是聊天网页 URL。
2. Base URL 示例为 `https://api.openai.com/v1`，不要重复追加 `/chat/completions`；实际地址和模型 ID 以服务商为准。
3. 点击“保存配置”，确认已配置且 Key 不回显，再测试连接。测试使用已保存配置，不是尚未保存的表单。
4. 打开“课程导师”，选择配置和课程/普通模式后发消息。课程模式会携带课程上下文；服务错误显示真实原因，没有自动重试或伪造回复。
5. RAG 需要另填可用的 Embedding 模型。资料保存在本地不代表模型推理离线：文本、问题和相关片段可能发往所配置的外部服务。只导入允许发送的资料。

RAG 的“检索资料类型”明确选择粘贴文本或文件资料，不会自动混合两者。选择文件或读取已保存资料会切到文件模式；清空资料库后文件模式保持为空，不会自动改用旧粘贴文本。切换资料后旧答案和本次评测撤下，需重新检索。取消文件选择不会丢掉当前输入。

模型服务可能收费，应用不附赠额度；当前不能假定无 Key 的本地模型配置受支持。不要把 Key 放进课程代码、聊天、截图或离线 HTML。

### 备份与换机

在桌面“模型设置 → 学习数据”导出 JSON。它包含完成记录、草稿、错题和聊天，不含模型配置、Key、RAG 资料库或全部掌握度状态。导入会替换学习记录和聊天，不会自动合并；接收端先做备份。换机后重新配置模型、重新导入需要的资料。

实际数据路径以模型设置显示为准，标准安装通常为：

- macOS：`~/Library/Application Support/Stewie LearnOS/stewie.db`
- Windows：`%APPDATA%\Stewie LearnOS\stewie.db`

同机升级前可先完全退出应用，再复制整个数据目录（不仅是可能仍有 WAL 的数据库文件）。备份含私人代码、聊天和加密 Key，应保密。普通换机优先用应用内导出/导入，不直接覆盖数据库。

升级时先备份再替换应用，核对课程数量与草稿。当前候选包可能共用 `1.0.0` 版本号，不能保证重复运行同版本安装器即可更新；正式版本发布前请确认包来源和构建提交。不承诺已提供自动更新。

## 选择建议

| 需求 | 入口 |
| --- | --- |
| 只看课程、写笔记、查看答案 | 离线 HTML 或 GitHub Pages |
| 实际运行 Python 练习 | 桌面完整版的内置 Worker（不是 Pages 或离线 HTML） |
| 导入本地资料做 RAG | 桌面完整版 |
| 使用个人模型 API | 桌面完整版，并在模型设置中保存 |

离线版和 Pages 版不会伪装成支持模型调用；如果页面没有桌面桥或本地运行时，相关入口会明确显示不可用原因。

## 开发者：运行简历项目演示

项目目录中的 `demo.py` 也使用随仓库提供的运行时。仓库根目录执行一次：

```bash
npm run prepare:python-runtime
desktop/.runtime/python/bin/python3.13 projects/recoverable-research-graph/demo.py
```

其余项目可替换最后的路径；演示使用确定性本地数据，不需要模型 Key 或网络。

也可以在仓库根目录直接运行 `npm run demo:projects`，按固定顺序执行全部简历项目；任一项目失败都会保留退出码并停止。
